## Overview

apex-cms provides a web interface for creating, maintaining, and publishing website content. Its primary focus is the management of pages and HTML-based material, offering a clear approach to organizing site updates and keeping routine publishing work manageable.

The project is intended for individuals and teams seeking a focused CMS for page editing and website maintenance. By concentrating on core content management activities, apex-cms supports page organization, content handling, and everyday publishing without adding unnecessary complexity.

## Using apex-cms

The CMS can be used to maintain website content, coordinate page revisions, and edit HTML-oriented site files.

A standard editing flow looks like this:

1. Start the project and open it in a browser.
2. Select the page or content area that requires an update.
3. Modify the HTML or content managed by the CMS.
4. Save the revision and publish it through the configured hosting environment.

For local use, launch the web server before opening the project directory in your browser.

## Configuration

The required settings can reside in the project files or within the hosting environment, based on the deployment approach.

A sample configuration structure is shown below:

```json
{
  "site_name": "apex-cms",
  "content_root": "/path/to/site",
  "pages_root": "/path/to/pages",
  "language": "HTML"
}
```

Update the paths and values so they correspond to the layout of your website and the environment where apex-cms is hosted.
